# Brainstorming

This folder is for rough working documents created during analysis, audits, brainstorming, and planning.

Files here are not binding project requirements unless promoted into `docs/` or `.project-board/`.

Suggested filename style:

```text
YYYY-MM-DD-short-topic.md
```

Project maintenance audits use this filename pattern:

```text
project-audit-YYYY-MM-DD.md
```

Files matching that pattern are audit reports and should not be treated as binding requirements unless their recommendations are promoted into `docs/` or `.project-board/`.
