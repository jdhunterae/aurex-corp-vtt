# P02-003 Add Scene GM Controls

## Status

Backlog

## Phase

Phase 2 - Scene Display

## Goal

Allow the GM to update the public scene through server-side routes or APIs.

## Acceptance Criteria

- [ ] GM can update scene title.
- [ ] GM can update scene description.
- [ ] GM can import or upload a local image into app-managed assets.
- [ ] GM can provide a URL for the server to download an image into app-managed assets.
- [ ] GM can select an app-managed scene image reference for public display.
- [ ] Scene updates are validated server-side.
- [ ] Scene update behavior is covered by tests.

## Notes

Depends on P02-001, P01-003, and P01-005.
