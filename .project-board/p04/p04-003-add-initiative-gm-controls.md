# P04-003 Add Initiative GM Controls

## Status

Backlog

## Phase

Phase 4 - Initiative Tracker

## Goal

Allow the GM to manage initiative through server-side routes or APIs.

## Acceptance Criteria

- [ ] GM can add, edit, reorder, and remove combatants.
- [ ] GM can add, edit, reorder, and remove non-creature initiative rows.
- [ ] GM can show or hide the overall initiative display.
- [ ] GM can mark combatants hidden, visible, or known.
- [ ] GM can reveal or hide AC per combatant.
- [ ] GM can choose combatant HP visibility mode.
- [ ] GM can configure how discovered HP numbers are displayed globally.
- [ ] Global discovered HP number display defaults to current/max.
- [ ] GM can advance the current turn.
- [ ] Invalid initiative updates are rejected server-side.
- [ ] Initiative update behavior is covered by tests.

## Notes

Depends on P04-002.
