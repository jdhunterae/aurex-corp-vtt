# P04-003 Add Initiative GM Controls

## Status

Backlog

## Phase

Phase 4 - Initiative Tracker

## Goal

Allow the GM to manage initiative through server-side routes or APIs.

## Acceptance Criteria

- [ ] GM can add, edit, reorder, and remove combatants.
- [ ] GM can mark combatants visible or hidden.
- [ ] GM can advance the current turn.
- [ ] Invalid initiative updates are rejected server-side.
- [ ] Initiative update behavior is covered by tests.

## Notes

Depends on P04-002.
