# Project Philosophy

## Build the tool you actually need

Aurex Corp VTT is not intended to compete with Foundry, Roll20, or Owlbear Rodeo.

Every feature should answer one question:

"Will this make running my game easier?"

If the answer is no, the feature probably doesn't belong.

---

## Keep the player display passive

Players should never need to interact with the display.

The display exists to communicate information chosen by the GM.

---

## Favor reusable systems over one-off features

Rather than implementing a "Round Counter," implement a generic numeric tracker.

Rather than implementing a "Torch Timer," reuse the tracker system.

Small, composable systems are preferred over specialized widgets.
