# UI Concepts

The application has two interfaces.

## Player

Goals

- Clean
- Readable from across a room
- Minimal distractions

Primary regions

- Scene
- Initiative
- Public trackers

---

## GM

Primary regions

Scene controls

Tracker controls

Initiative controls

Notes

Quick actions

---

The GM interface prioritizes speed over appearance.

Every common action should be accomplishable with one or two clicks.
